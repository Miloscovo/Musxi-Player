# Application icon

Artwork supplied by the project owner. `musxi.png` retains the original black background, black cutouts and white record-and-note artwork. The original RGB pixels are tightly cropped and centered without generative redrawing, with the artwork's longest dimension filling the canvas. The square has a 20% corner radius with transparent exterior corners and smooth alpha edges; its interior and white artwork remain fully opaque.

`musxi.ico` contains 32-bit PNG frames at 16, 20, 24, 32, 40, 48, 64, 128 and 256 pixels. The application, tray and installer share this artwork. The Windows build applies it to a copy of the CEF bootstrap; the SDK file is not modified.
