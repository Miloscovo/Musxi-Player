| 文件 | 页面与内容 |

| `personalized-player.png` | 《SAKURA》— いきものがかり，酷狗音乐来源的封面播放页；当前进度 2:03 / 5:53 |
| `personalized-lyrics.png` | 同一首歌曲与进度，日文歌词、中文译文及当前行高亮 |
| `personalized-queue.png` | 同一播放页上打开真实队列，展示玻璃模糊与透明层；包含 Kotoha、miu-clips、fripSide 等歌曲 |

截图由临时工具调用 Android `PixelCopy`，直接读取 Musxi `MainActivity` 的应用窗口，并在读取区域中排除系统栏；不截取其他应用的游戏悬浮小窗。未后期拼接、重绘、换图或伪造歌曲信息。三张 PNG 均为 1080 × 2293 像素，保持应用窗口的原始像素。截图时暂停播放，未更改账号、收藏或歌单。

### 使用的参数

通用设置读取自手机 `musxi-settings-v1`，壁纸参数读取自两份已应用清单并核对 CRC；截图结束后，两份清单与设置文件的字节均未变化。

| 项目 | 设置值 | 含义 |
| --- | --- | --- |
| 主题模式 | `DARK` | 深色模式 |
| 主题色 | `TEAL` / 松石青 | 深色主题主色 `#8DCFC5`；播放页部分控件与歌词仍可跟随封面取色 |
| 透明效果 | `true` | 开启；本机未开启省电模式，队列中可见实际玻璃效果 |
| 歌词字号 | `LARGE` | 原文基础 18sp / 行高 27sp；译文 14sp / 行高 21sp；当前行另有页面既有放大效果 |
| 歌词颜色 | `COVER` | 跟随封面取色 |
| 译文偏好 | `AUTO` | 自动判断；本曲显示已有中文译文 |
| 播放页壁纸 | 开启，强度 `150`，缩放 `1.0` | 已应用图片 1500 × 2500；取景中心 `(0.5451744, 0.5)` |
| 界面壁纸 | 开启，强度 `150`，缩放 `1.0` | 已应用图片 1080 × 1905；取景中心 `(0.4520756, 0.5)`；作用于曲库等页面，未出现在本组三张中 |
| 显示条件 | 1080 × 2414，480dpi，系统字体倍率 `1.0` | 手机当时已保存的显示条件；截图工具未修改 |

壁纸强度的可选范围是 0–150，表示可见程度，不等同于 150% 不透明度。取景中心以整张图片的宽高归一化，`(0.5, 0.5)` 为居中，`1.0×` 为填满窗口的基础缩放；实际取景会按页面比例限制到图片边界。两份壁纸清单里保留的历史 `scope` 字段均为 `PLAYER`，实际作用范围由播放页／界面两份独立槽位决定。

壁纸为开发者个人导入的图片，不是应用随包提供的默认壁纸；歌曲封面、歌词与译文为相应歌曲内容，相关权利归各自权利人。此处仅保存应用效果截图，不提供壁纸原图或歌曲音频。临时截图工具与原始检查材料保留在项目忽略的 `.local/` 中，不进入应用正式代码或发行包。
