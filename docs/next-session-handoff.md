# 当前开发接续

更新：2026-10-23。源码版本 `0.1.0-alpha02`；v0.1 很不完善，仅建立可继续修改和实机测试的基础。产品范围见 [本次增量](v0.1-foundation.md)，证据边界见 [0.1 验收](android-0.1-acceptance.md)。

## 已整合

正式 Compose 页面已接账号/曲库/搜索、播放器、换源、双语歌词、红心、队列点击/拖动/删除清空。歌词操作共用右侧中心线，译文字标按可见字形居中；排版使用系统字体与统一层级，短文档整组居中、长文档随当前行组定位。

后端含连接恢复、前台资格门禁、收藏写后核实与失效、独立 AUDIO 通道、保守换源匹配、行级译文及独立刷新。队列跳转不重建票据，拖动固定开始 revision，连接/账号/队列变化取消手势，失败可见。

本次复用 PC 同源图标；自适应前景增加 18dp inset，防止完整方形原图被系统遮罩过度裁切。legacy 密度资源保留。

## 下一步

1. 各平台正式页面主流程、队列编辑及失败/旧 revision 拒绝矩阵实机验收。
2. 中文/双语、长句、首尾和大字体视觉，修浅底状态栏图标对比度。
3. 明确实现或移除空入口：持久队列恢复、最近播放、真实封面、主题与更多菜单；输出选择暂缓。
4. 自然长后台、深度 Doze、真实系统回收、来电与输出切换专项；按包、场景区分状态证据与听音。
