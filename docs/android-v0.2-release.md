# Musxi Player Android v0.2

Android v0.2 发布，应用版本 `0.2.0`，versionCode 5。安装包发布在 [独立安卓仓库](https://github.com/qwt1011/Musxi-Player-Android/releases/tag/v0.2)，源码另向 [PC 上游 android/development](https://github.com/Miloscovo/Musxi-Player/tree/android/development) 提交 PR。

## 下载与安装

- `Musxi-Player-0.2.0.apk`：正式签名包，包名 `tech.musxi.player`，支持 Android 8.0 / API 26 及以上。
- `SHA256SUMS.txt`：安装包 SHA-256 校验值。
- `update-manifest.json`：版本、包名、文件大小、SHA-256 和公开签名证书指纹，供应用内更新校验。

这是该正式包名的首次公开发布。旧 v0.1 及本机开发版使用 `tech.musxi.player.dev`，可与本版同时安装，账号、设置及队列各自保存；首次打开正式版需要重新连接账号。保留旧开发包即可保留原数据。后续正式版沿用同一发布签名，支持覆盖更新。私钥与密码不随源码或安装包发布。

## 本版变化

- 导航栈、连续播放器与玻璃材质；Android 13 及以上使用折射，Android 12 使用磨砂，更低版本或关闭透明效果时使用实色。重做“我的”页及三平台账号子页，显示真实头像、昵称和会员状态。
- 播放失败原因与实际音源提示；会员可播放时优先原平台，原平台确认无权限后进行严格匹配换源。换源偏好、成功映射复用及下一首能力预取，保留原队列身份。
- 三平台头像校验与加密保存、同代次资料刷新、断网显示已保存头像；酷狗异常空歌单保护，首次可疑空结果保留已有曲库。
- 默认音质与会员刷新、酷狗音质菜单错误隔离及短时缓存；统一设置、缓存占用与清理接口。缓存清理保留账号和播放日志。
- 歌词磁盘缓存与手动匹配、随机播放实际顺序、最近播放移除、歌单分类；三平台歌手/专辑及缓存歌单搜索后端接口。
- 正式签名构建与应用内更新：只读取独立安卓仓库的 Releases，校验下载大小、SHA-256、包名、版本及签名，再进入系统安装确认；正式包最多每日自动检查一次，开发包仅手动查看。

## 验证与限制

Kotlin 2.3.21 / Backdrop 环境下，七模块 1599 项 JVM 测试通过，六模块 Lint 0 错误。第五批最终头像策略另通过 core 355 项回归。发布时再构建 `0.2.0` 的签名 Release，验证 v2 签名、元数据和正式清单，排除调试入口，并执行 Release Lint。

发布前的同一生产代码在 PJF110 / Android 16 开发包完成三平台头像下载/持久化、“我的”及账号子页、真断网冷启动、酷狗原平台播放、QQ 无权限严格换源及正常歌单读取。该设备样本中 QQ 换到酷狗约 1.48 秒进入播放，下一首约 0.21 秒；这不是所有歌曲和网络的性能保证。详见 [第五批交付](backend-batch5-delivery-20261101.md)。

当前仍在持续完善。真实退出账号后的头像、其他 Android 版本、新一轮长时间待机/来电、玻璃拖动和长列表性能没有全部完成真机验证；歌手/专辑和歌单内搜索的完整产品入口、锁屏歌词及逐字歌词仍需后续开发。正式更新安装流程此前在独立测试包使用受控下载验证，不能等同于本版已完成线上双版本更新。
