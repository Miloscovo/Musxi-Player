## P0 · 酷狗会员歌曲恢复自动换源（回归）
- 现象：真机上大量酷狗歌单歌曲停在"暂无可用音源 · 平台返回异常"，既不换源也不跳过。alpha03 时同类歌曲会自动换到 QQ音乐 / 网易云。
- 原因（前端核对代码）：`KugouLibraryApi.audio()` 在基础取流返回 permission 后改走 `authorizedAudio()`；授权链失败时抛出 identity / protocol 等，`KugouPlaybackProvider.mapFailure` 映射为 `PlaybackFailure.PROTOCOL`。`MusxiPlaybackService` 只对 PERMISSION / UNAVAILABLE 调 `offerAlternative`，`QueueRecoveryPolicy` 对 PROTOCOL 直接 STOP。
- 要求：
  1. 基础取流已判定无权限时，授权链的任何失败都不得改变"无权限"的分类，仍按 PERMISSION 进入自动换源；授权链的具体原因可以另外记录，供界面展示。
  2. 账号会员状态为 NO 时不调用授权链（不发签名请求），直接按无权限处理，缩短等待；UNKNOWN 时可以试一次。
  3. 建议：歌曲级的 PROTOCOL（单曲解析或身份校验失败）也允许自动换源；账号级失败（登录过期、限流、风控）不换源，避免在其他平台连续请求。是否采纳由你判断，写明理由。
- 验收：单测覆盖"授权链各类失败后仍自动换源"和"会员为 NO 时不发授权请求"；真机上用使用者的酷狗歌单验证会员歌曲能自动换到其他平台。

## P0 · 自动换源的偏好与"最接近"规则
- 产品负责人希望：原平台放不了时，默认自动播放其他平台最接近的同名同歌手版本。
- 现有严格规则（`SourceMatchPolicy`：歌手集合一致、标题规范化后一致、时长差不超过 3 秒且不超过 2%、排除现场 / 翻唱 / 伴奏 / 纯音乐 / 重制等）保留为自动换源的默认标准。
- 新增：
  1. 持久化偏好"放不了时自动换到其他平台"，默认开。关闭时一律进入选择，不自动播放。
  2. 持久化偏好"放宽时长"，默认关：标题和歌手集合一致、没有版本标记，但时长差超过严格阈值（建议上限 15 秒或 8%，由你定）时也可以自动选用；排序按时长差从小到大、同专辑优先。这类候选带"放宽匹配"标记和时长差，前端会提示。
  3. 自动换源成功后，在状态里给出所选平台以及是否放宽，前端据此提示"已换到 QQ音乐 的版本"。
- 验收：单测覆盖排序和两个偏好；《晴天》被换到翻唱版这类情况，在两种偏好下都不得自动选中。
