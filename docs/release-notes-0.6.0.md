# Musxi Player 0.6.0

## 歌词与外观

- 新增液体彩胶、方形封面和隐藏播放器三种歌词页样式，支持随歌曲封面取色。
- 新增模糊歌曲封面背景与歌词字体颜色设置，优化高亮、翻译和窄窗口布局。
- 优化歌词滚动、侧栏与播放栏收起展开动画，主界面自动匹配显示器刷新率，最高 120 FPS。
- 优化搜索栏焦点和按钮悬停效果，快捷键不再触发多余的绿色选中框。

## 音乐库与在线体验

- 本地文件夹歌单和“本地歌曲整合”新增重新扫描，扫描完成后统一更新列表；重新识别新增歌曲并移除失效引用，不删除磁盘文件。
- 在线歌单与歌曲列表采用骨架加载，优化启动时歌单入口就绪状态和占位数量。
- 优化封面加载与失败回退，避免无封面歌曲反复显示加载动画，并修复网易云封面和头像获取。
- 加快在线歌单与搜索响应：成功结果最多复用 30 秒，同步或歌曲增删后失效；优化多平台同步、批量歌曲获取及封面请求并发。
- 修复播放结束及部分 FLAC 歌曲再次播放异常，完善单曲循环图标和歌单交互。

## 安装与源码

- Windows x64 安装包：`MusxiPlayer-Setup-0.6.0.exe`。
- `MusxiPlayer-Update-0.6.0.json` 为应用更新校验清单，无需手动打开。
- 本版本应用源码：[v0.6.0](https://github.com/Miloscovo/Musxi-Player/tree/v0.6.0)。
- 第三方源码、固定版本、许可证与重链接材料获取说明：[源码交付索引](https://github.com/Miloscovo/Musxi-Player/blob/efd72195e2202325c8a8af8b79068f63ccd1cd18/docs/release-source-delivery.md)。

在线响应速度仍受平台接口及网络状况影响。完整安装升级流程建议先在测试环境验证。
