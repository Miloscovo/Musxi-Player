# 本地音频导出与整理备份／恢复

日期：2026-11-08。接续目录关联后端，按用户授权推进音频导出与整理数据备份。正式界面待 CC，手机尚未接入；本轮不提交、推送、发布或操作平台数据。现行接口见[本地音频合同](frontend-backend-contract-local-audio.md)，当前排期见[开发接续](next-session-handoff.md)。

## 本轮实现

- 原始音频导出：COPY／REFERENCE 复用已有读取能力，64 KiB 流式复制、大小边界、取消、进度限频；COPY 边复制边核对内容摘要，不转码、不写回标签、不删除源文件。
- SAF 输出限定新建空文档，要求系统实际写授权，拒绝非空、无法确认空、目录与库内引用源别名，失败或取消尝试删除未完成输出。提供方清理失败单独反馈，不把半成品误报成功。
- 整理备份：版本 1 自描述 envelope、严格 UTF-8、字段／列表／32 MiB 上限、SHA-256 完整性校验，不引入序列化框架或压缩依赖。
- 预览后合并：完整校验后暂存在后端，确认时使用已验证内容及 revision；匹配按导入模式与精确来源摘要，未匹配项计数并跳过，不按标题猜测。
- 保留当前整理：同 ID 文件夹不覆盖名称／偏好，现有成员不重排，已有别名／进度／游标优先，书签去重；缺失字段才补充。全部数据库写入同一事务，超限、失败或提交前取消整体回滚，重复无变化不增加 revision。

备份包含私人名称和进度，但不包含音频、文档 URI、系统授权、目录关联、账号或活动队列。导出音频与整理备份是两个入口；跨设备需要先导入音频并重新授权引用来源。摘要用于检错，不提供加密或对不可信来源的身份认证。

导入／目录刷新与传输互斥，普通短整理和服务进度保存可继续；导出期间所需副本和权限暂时保留，用户删除或重关联之后的迟到导出拒绝成功，并清理输出。后端状态不公开 URI，`cleanupFailed` 提示用户检查残留。

## 使用边界与接续

提供方无法确认新文档大小时需更换目标；进程终止或断电后不能保证外部目标自动清理，用户可在所选位置检查。REFERENCE 没有可靠修改时间时，同大小替换仍可能无法识别；备份来源匹配同样受提供方文档身份稳定性影响。

当前是保留数据的整理合并，未匹配音频不会成为不可读的空壳条目。打包音频的一键迁移、批量目录导出、恢复冲突的覆盖策略与加密备份留待后续，不将整理文件宣传为完整媒体备份。后续优先检索／批量整理和 CC 正式接线，再按实际需求补倍速、AB、本地 LRC、章节和封面。
