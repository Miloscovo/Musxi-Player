# 歌词与悬浮组件

悬浮组件是常驻内置功能，在设置 → 歌词与组件中配置，无需在扩展中启用。原桌面歌词和游戏歌词已合并为唯一的“歌词悬浮组件”，歌曲信息仍为独立窗口。扩展入口保留，当前显示“暂无扩展”。主歌词播放页面保持原样。支持 Windows 窗口化、无边框全屏游戏，不能承诺真正独占全屏支持。

- 歌词支持单行当前句（可附译文）与多行滚动，模式立即生效并保存；两种模式均支持平面／斜向立体。
- 两个组件共用“组件置顶”开关，默认开启并保存。关闭后按普通窗口层级显示，可能被游戏或其他应用遮挡；切换显示器或刷新率不会重新开启置顶。
- 底栏“词”和托盘歌词开关只控制歌词窗；组件显隐快捷键继续成组控制歌词与歌曲信息。位置、模式、字号与编辑状态由同一窗口管理，不再出现两套歌词。
- 歌词胶囊工具栏随悬停显示，包含播放、切歌、译文和字号，关闭使用编辑标题栏右上角的“关闭”，右键不再切换。颜色与高亮跟随主歌词页面，取消独立颜色菜单；译文开关与主歌词页同步。悬浮歌词使用独立的 16–48px 字号，单行、多行共用。
- 系统鼠标可见并移入任一组件时，该组件自动进入编辑并接管焦点，可拖动和缩放；另一个组件保持锁定，歌词工具栏仅在悬停歌词时显示。按约 80ms 检测，鼠标移出后自动锁定，并在仍拥有焦点时返回原程序；用户已切换应用时不会抢回。拖动、缩放或鼠标捕获期间保持编辑，操作结束后再判断。组件被其他窗口遮挡时不会因鼠标经过其后台区域而抢焦点。
- “完成”结束编辑并阻止本次悬停再次进入，移出再进入后恢复；旧解锁入口和工具栏锁定按钮已移除。通过快捷键／设置按钮主动进入的组件编辑保持到主动结束，允许继续编辑歌曲信息；歌词工具栏仍仅悬停时显示。自动隐藏选项继续优先，隐藏时可用编辑快捷键恢复。悬停接管焦点可能使失焦就最小化的原生全屏游戏退出前台，请使用窗口／兼容模式。
- 首次迁移优先保留已显示的原游戏歌词布局和字号，使用多行；否则原桌面歌词正在显示时沿用桌面布局和字号、使用单行。都隐藏则保持隐藏并默认多行；原未启用用户不会自动弹出组件。旧桌面配置保留，只迁移一次，后续使用版本 2 组件配置。

- 歌曲信息和滚动歌词是两个独立的窗口，可以分别开关、拖动和缩放。设置中不再提供总显示开关，独立开关反映各自的显示选择；成组隐藏后，单独开启一个开关只显示对应组件，成组显隐快捷键仍保留。
- 歌曲信息组件透明度在歌词与组件设置的“歌词样式”上方独立调整，0% 不透明、100% 全透明。首次继承当前有效外观透明度并保存，此后不再跟随全局透明效果；拖动立即同步，编辑与游玩一致，文字、封面和按钮保持清晰。横向拉伸松开后，歌曲内容与内边距按窗口宽度等比缩放，以默认 360px 宽度为原始大小，高度自动适配。“完成／关闭”保持固定大小并悬浮在右上方，长歌名省略并避让按钮；进入和退出编辑不改变窗口尺寸。
- 编辑歌曲信息组件时，标题栏和边缘拖动区域使用约 1/255 不透明度的鼠标命中底，避免完全透明像素穿透导致无法拖动；保存的透明度不变，结束编辑后移除命中底，100% 透明时恢复真正全透明背景。
- 歌曲信息封面跟随歌词页面的播放器样式：黑胶使用同款播放动画、暂停停转，方形显示封面，选择“无”时只隐藏封面并保留歌曲文字与进度；外观设置修改后即时同步。
- 平时两个窗口鼠标穿透，不抢走游戏焦点。
- “鼠标出现时隐藏组件”默认关闭，沿用原“鼠标悬停时隐藏组件”已保存的开关值。开启后，仅当其他程序在前台且组件锁定时，按约 80ms 间隔检测系统鼠标：鼠标可见即同时隐藏歌词和歌曲信息，鼠标隐藏后恢复原先开启的组件，不依赖鼠标位置、不改变组件显示开关或焦点。编辑期间保持显示；游戏自绘光标的系统可见状态需逐游戏验证。为兼容已有设置和调用方，仍沿用 `hideOnHover` 字段与桥接命令。
- 进入编辑时组件取得前台和输入焦点，点击可切换编辑另一组件；编辑快捷键松开后才交接焦点，仍透传原按键。结束编辑、隐藏所有组件时，若焦点仍在组件内则返回原窗口；用户已切到其他应用时不会抢回。原生全屏失焦可能最小化，编辑前请使用窗口模式或通用窗口兼容。
- 开启置顶时，组件显示或切回其他应用会恢复置顶顺序，避免 Minecraft 等置顶游戏窗口盖住组件。
- 点击“编辑组件”，或使用对应快捷键，拖动标题栏或边缘空白来移动组件，歌词正文用于滚动浏览；边缘仍可缩放。编辑标题栏只保留“完成”和“关闭”，不显示组件名称、选歌或跟随按钮；关闭仅隐藏对应组件。歌曲信息不再提供播放和切歌按钮，歌词悬停工具栏保留原有操作。完成编辑后重新穿透，歌词恢复跟随当前句。
- 滚动歌词仅在编辑时显示背景和边框，游玩时背景透明。
- 歌词颜色和高亮与歌词界面一致：当前原文句跟随主题色或封面色，其他同步句和译文使用次要文字色，纯文本歌词使用正文色；无可用封面时回退到主题色。
- 歌词区域上下边缘渐隐，游玩和编辑时均生效；背景、标题栏和按钮保持清晰。
- 设置中的“歌词样式”可选择平面或斜向立体，默认平面并记住选择。斜向立体为左近右远、向右上延伸的固定透视（左右 28°、旋转 -6°，对应原倾斜程度 100%），不再提供倾斜滑块，忽略旧倾斜数值，编辑与游玩一致。
- 斜向立体的当前句与译文一起放大约 6%，并提高绘制层级，以 0.3 秒过渡呈现视觉前移；其他句、原有行距和滚动定位保持原样，系统要求减少动画时直接切换。平面样式不使用此效果。
- 歌词行距、译文间距、高亮过渡与歌词界面一致，滚动共用 0.48 秒动画和缓动曲线；系统要求减少动画时直接定位。
- 单行歌词切句时，原文与译文整组以 0.3 秒、8px 位移上移淡出和从下方淡入；首次加载、切歌和调整尺寸不触发切句动画。系统要求减少动画时直接切换，平面与斜向立体共用此行为，多行保持原有滚动。
- 歌词组件渲染上限跟随所在显示器刷新率，最高 120，无法获取时为 60；跨屏或刷新率改变时更新，实际帧率仍受游戏负载影响。
- 拉伸策略与主界面一致：拖动期间固定 CEF 网页布局，按原比例裁切或补齐画面与背景，松开后合并尺寸更新并等待最终尺寸的新帧；与主界面共用像素补齐和圆角处理。原有帧率、样式、编辑交互和歌曲信息自动高度保持不变。`tests/cef-game-overlay.ps1 -ResizeOnly` 使用真实鼠标拉伸两个组件，验证拖动时布局固定、松开后重新排版及最终尺寸。
- 组件隐藏时暂停播放状态订阅与内容轮询，重新显示时立即同步；歌词内容未变化时复用行数据，歌曲信息的封面和标题与进度更新分开处理。原生等尺寸画面直接复制，尺寸舍入时保留透明补边；这些优化不改变现有动画或帧率上限。
- 游戏完全铺满时若看不到组件，可打开“通用窗口兼容”工具。Minecraft 和其他游戏统一手动选择，不再自动识别或接管；旧 Minecraft 自动偏好被忽略。工具默认关闭，启用状态和窗口选择不跨播放器重启保存。先将游戏切换到带标题栏的普通窗口，再刷新列表，按窗口标题和程序名选择，点击“应用”。游戏客户区完整覆盖所在显示器，细边框位于屏幕之外，不留空隙、不裁切、不抢焦点，也不代发按键或修改驱动、游戏文件。自绘无标题栏窗口及真正独占全屏不能直接应用；自定义尺寸限制导致验证失败时尝试恢复原布局。
- 一次只管理一个窗口，恢复后才可选择另一个。切换设置页面或切回游戏不会关闭工具。点击“恢复原布局”、关闭工具或正常退出播放器时恢复同一游戏会话的原窗口；若用户自行移动、缩放或切换模式，则保留用户的新布局并停止接管，“结束管理”后可刷新重新选择。游戏退出后丢弃管理记录，重启游戏也不会自动应用。恢复失败会保留备份供重试；播放器异常终止无法保证恢复，可重启游戏重置窗口。管理员游戏需手动以同等权限启动播放器；不同游戏、DPI、显示器与驱动组合仍需实测。
- 旧快捷键配置中的选歌面板和截图绑定会被丢弃，其他绑定与全局开关保留。
- 设置 → 快捷键提供“显示 / 隐藏悬浮组件”“编辑 / 锁定悬浮组件”。在游戏中使用前需要设置绑定并启用全局快捷键；默认不占用按键。
- 组件显隐、编辑快捷键在文本输入时仍可使用，播放快捷键在输入时暂停，避免影响搜索词输入。录制新快捷键时所有全局快捷键暂停。
- 启用全局快捷键后，全部绑定使用不吞键的监听，同一次按键会同时执行播放器和前台程序原操作；隐藏组件后也继续透传。
- 管理员权限游戏需要手动以管理员身份运行播放器；播放器会保留用户选择的管理员权限。普通启动仍使用普通权限，不会自动申请提权。

组件位置、尺寸和显示选择会记住；编辑状态不跨启动保留。关闭某个组件不会停止音乐。桌面与游戏共用同一歌词窗口。

播放、歌词和歌曲信息来自已有原生播放状态；组件只访问当前曲目。搜索和歌单浏览仍在主窗口进行，两个悬浮组件不会改变主窗口的浏览状态。

保留 `gameOverlay.*` 与旧 `desktopLyrics.*` 桥接名称；旧歌词入口转向统一窗口，旧独立颜色与译文设置命令返回明确提示，译文改由共享的歌词页面设置控制，旧扩展停用命令不再停用常驻功能。新增置顶、歌词模式和字号状态，播放接口不变。设置存储位置及验证见原生实现和 `tests/cef-game-overlay.ps1`。
