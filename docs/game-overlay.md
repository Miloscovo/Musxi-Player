# 游戏内悬浮组件

在侧边栏“扩展”中打开内置的“游戏内悬浮组件”模块，再前往设置 → 游戏内悬浮组件配置。启用模块只解锁设置和快捷键，不会自动显示悬浮组件；需要时手动打开“显示悬浮组件”。首版支持 Windows 窗口化、无边框全屏游戏；游戏菜单中的“全屏”也可能经过 Windows 全屏优化，不能据此承诺真正的独占全屏支持。

- 歌曲信息和滚动歌词是两个独立的置顶窗口，可以分别开关、拖动和缩放。
- 歌曲信息组件透明度在游戏内悬浮组件设置的“歌词样式”上方独立调整，0% 不透明、100% 全透明。首次继承当前有效外观透明度并保存，此后不再跟随全局透明效果；拖动立即同步，编辑与游玩一致，文字、封面和按钮保持清晰。高度随内容自动调整，编辑时为标题栏与控制按钮增高，宽度仍可缩放。
- 编辑歌曲信息组件时，标题栏和边缘拖动区域使用约 1/255 不透明度的鼠标命中底，避免完全透明像素穿透导致无法拖动；保存的透明度不变，结束编辑后移除命中底，100% 透明时恢复真正全透明背景。
- 歌曲信息封面跟随歌词页面的播放器样式：黑胶使用同款播放动画、暂停停转，方形显示封面，选择“无”时只隐藏封面并保留歌曲文字与进度；外观设置修改后即时同步。
- 平时两个窗口鼠标穿透，不抢走游戏焦点。
- “鼠标出现时隐藏组件”默认关闭，沿用原“鼠标悬停时隐藏组件”已保存的开关值。开启后，仅当其他程序在前台且组件锁定时，按约 80ms 间隔检测系统鼠标：鼠标可见即同时隐藏歌词和歌曲信息，鼠标隐藏后恢复原先开启的组件，不依赖鼠标位置、不改变组件显示开关或焦点。编辑和选歌期间保持显示；游戏自绘光标的系统可见状态需逐游戏验证。为兼容已有设置和调用方，仍沿用 `hideOnHover` 字段与桥接命令。
- 进入编辑时组件取得前台和输入焦点，点击可切换编辑另一组件；编辑快捷键松开后才交接焦点，仍透传原按键。结束编辑、隐藏所有组件或停用模块时，若焦点仍在组件内则返回原窗口；用户已切到其他应用时不会抢回。原生全屏失焦可能最小化，编辑前请使用窗口模式或通用窗口兼容。
- 组件显示或切回其他应用时会恢复置顶顺序，避免 Minecraft 等置顶游戏窗口盖住组件；选歌面板打开时保留面板排序。
- 点击“编辑组件”，或使用对应快捷键，拖动标题栏或边缘空白来移动组件，歌词正文用于滚动浏览；边缘仍可缩放。完成编辑后重新穿透，歌词恢复跟随当前句。
- 滚动歌词仅在编辑时显示背景和边框，游玩时背景透明。
- 歌词颜色和高亮与歌词界面一致：当前原文句跟随主题色或封面色，其他同步句和译文使用次要文字色，纯文本歌词使用正文色；无可用封面时回退到主题色。
- 歌词区域上下边缘渐隐，游玩和编辑时均生效；背景、标题栏和按钮保持清晰。
- 设置中的“歌词样式”可选择平面或斜向立体，默认平面并记住选择。斜向立体为左近右远、向右上延伸的固定透视（左右 28°、旋转 -6°，对应原倾斜程度 100%），不再提供倾斜滑块，忽略旧倾斜数值，编辑与游玩一致。
- 斜向立体的当前句与译文一起放大约 6%，并提高绘制层级，以 0.3 秒过渡呈现视觉前移；其他句、原有行距和滚动定位保持原样，系统要求减少动画时直接切换。平面样式不使用此效果。
- 歌词行距、译文间距、高亮过渡与歌词界面一致，滚动共用 0.48 秒动画和缓动曲线；系统要求减少动画时直接定位。
- 歌词组件渲染上限跟随所在显示器刷新率，最高 120，无法获取时为 60；跨屏或刷新率改变时更新，实际帧率仍受游戏负载影响。
- 组件隐藏时暂停播放状态订阅与内容轮询，重新显示时立即同步；歌词内容未变化时复用行数据，歌曲信息的封面和标题与进度更新分开处理。原生等尺寸画面直接复制，尺寸舍入时保留透明补边；这些优化不改变现有动画或帧率上限。
- 选歌面板复用现有播放器，保留当前搜索、歌单、队列和滚动位置。打开时临时置顶并接收键盘输入；“返回游戏”使用与壁纸预览一致的背景浮条，在播放栏上方约 12px 居中，不占用独立布局行；与壁纸预览同时出现时上下排列。页面滚动时保持可见，点击或使用选歌面板快捷键收起。
- 选歌面板快捷键同样透传给游戏，松开按键后再切换面板；打开成功时必须实际取得播放器焦点，收起后返回游戏。
- Minecraft 等游戏可能在原生全屏失焦时自动最小化。若希望选歌时保留背景游戏画面，需要使用窗口化或无边框窗口；收起面板时会恢复被最小化的原游戏窗口。
- 游戏完全铺满时若看不到组件，可打开“通用窗口兼容”工具。Minecraft 和其他游戏统一手动选择，不再自动识别或接管；旧 Minecraft 自动偏好被忽略。工具默认关闭，启用状态和窗口选择不跨播放器重启保存。先将游戏切换到带标题栏的普通窗口，再刷新列表，按窗口标题和程序名选择，点击“应用”。游戏客户区完整覆盖所在显示器，细边框位于屏幕之外，不留空隙、不裁切、不抢焦点，也不代发按键或修改驱动、游戏文件。自绘无标题栏窗口及真正独占全屏不能直接应用；自定义尺寸限制导致验证失败时尝试恢复原布局。
- 一次只管理一个窗口，恢复后才可选择另一个。切换设置页面或切回游戏不会关闭工具。点击“恢复原布局”、关闭工具、停用模块或正常退出播放器时恢复同一游戏会话的原窗口；若用户自行移动、缩放或切换模式，则保留用户的新布局并停止接管，“结束管理”后可刷新重新选择。游戏退出后丢弃管理记录，重启游戏也不会自动应用。恢复失败会保留备份供重试；播放器异常终止无法保证恢复，可重启游戏重置窗口。管理员游戏需手动以同等权限启动播放器；不同游戏、DPI、显示器与驱动组合仍需实测。
- 设置 → 快捷键新增“显示 / 隐藏游戏组件”“编辑 / 锁定游戏组件”“打开 / 收起游戏选歌面板”。在游戏中使用前需要设置绑定并启用全局快捷键；默认不占用按键。
- 组件显隐、编辑和选歌面板快捷键在选歌面板的搜索框中仍可使用，播放快捷键在输入时暂停，避免影响搜索词输入。录制新快捷键时所有全局快捷键暂停。
- 模块启用时，全部全局快捷键使用不吞键的监听，同一次按键会同时执行播放器和游戏原操作；模块关闭后恢复原有系统热键注册方式。
- 管理员权限游戏需要手动以管理员身份运行播放器；播放器会保留用户选择的管理员权限。普通启动仍使用普通权限，不会自动申请提权。
- 禁用模块会关闭组件、撤销选歌面板的临时置顶，并隐藏对应设置分类与四项快捷键；已保存的组件位置、独立开关和快捷键绑定会保留。禁用期间游戏快捷键不响应，也不会占用全局按键。

组件位置、尺寸和显示选择会记住；编辑状态与选歌面板置顶状态不跨启动保留。关闭某个组件不会停止音乐。现有桌面双行歌词保留，可单独使用。

播放、歌词和歌曲信息来自已有原生播放状态；组件只访问当前曲目。搜索和歌单浏览仍在主窗口进行，两个悬浮组件不会改变主窗口的浏览状态。

新增 `gameOverlay.*` 桥接命令，保留现有 `desktopLyrics.*` 和播放接口。设置存储位置及验证见原生实现和 `tests/cef-game-overlay.ps1`。
