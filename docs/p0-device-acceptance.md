中间包覆盖安装后强停，通过广播创建新进程，先打开各平台固定元数据失败开关再读取页面。三平台歌单和上述歌曲首页均从 CACHE 读出，数量/带封面数与联网值一致，storageError=false，证明地址字段已落盘并在新进程读回。网易云、酷狗为 CONNECTED 且刷新返回模拟 network；QQ 此次真实登录恢复落到 RETRYABLE_ERROR，缓存仍显示并标记 account_unverified，不向平台发起未验证曲库请求。脚本原先要求 QQ 的错误为 network，因而该条件超时；这是验收条件不适用于待验证账号，不能记为通过了该条件。

随后仅执行普通 QQ restore，恢复 CONNECTED 后联网读取成功，无需重新登录。详情对照中间包另验证已连接 QQ 的模拟刷新失败：歌单 1/1、歌曲 7/7，source=CACHE、error=network、storageError=false。所有开关随后恢复；未关闭手机网络。这组结果分别覆盖冷磁盘读取、待验证缓存和刷新失败保留，不能混写成真实断网验收。

## 播放

先测包 QQ 搜索首曲原来源不可播，真实候选 20 项，自动选中网易云来源；queueSize=1、queueIndex=0、queuePlatform=QQ、sourcePlatform=NETEASE，独立 resolver 也报告 NETEASE。原队列 key 保留，标题/歌手/专辑/封面与选中候选一致。故障注入计数为 0。

用户反馈“是刚才的‘晴天’吗？是的话确实听到了，现在没声音”。按带条件的听音反馈保留，不能外推三平台全部听音正常。无声时进度 112425ms、时长 112416ms，无缓冲或失败；随后显式 resume 从开头播放，暂停后 3 秒进度相等，再继续进度增长，来源与元数据保持一致。不能用这条同名候选保证原唱或同录音；平台时长也不代表已核验完整录音。

网易云、酷狗搜索首曲均直接以各自平台起播，一项队列、正确 key、专辑和封面比较一致，观测 3 秒进度增长且无播放错误；这两项仅为播放器状态证据，没有分别取得用户听音确认。

中间包和最终包均从 QQ 本人歌单建立 7 项队列，首曲原源不可播后以网易云替代。将进度跳到曲尾前 1 秒后由播放器正常完成曲尾接续，automaticTransitions 增加 1，索引从 0 到 1，实际取流回到 QQ，原队列第二首 key 和元数据比较一致。这里是 seek 辅助曲尾检查，没有完整听完该曲；中间包还验证 previous 回到索引 0 并重新走原曲候选流程。

首曲曾出现“当前播放与候选搜索摘要不完全相等”；单独对照实际来源的单曲详情，一次即时检查 cover=false，之后重查四项全相等。最终包增加 debug 内存中的本次实际取流 metadata 对照：网易云原源与 QQ→网易云替代时，resolvedKeyMatches / resolvedMetadataMatches 均为 true。再次请求单曲详情时曾观测到封面路径相同、域名不同，标题/歌手/专辑相同；因此重新请求得到的 URL 或候选摘要逐字相等不能作为唯一标准。播放器采用本次实际取流的资料，公开封面探测成功，没有因此修改生产代码。歌单第二首与 QQ 单曲详情四项也全部一致。

QQ、酷狗的 provider 按既有约定返回 StreamLease(null)，显示资料来自已提交歌曲/候选，不能要求它们提供网易云式 resolver metadata。最终 host 脚本最初对此要求过严，导致酷狗播放成功、metadataMatches=true，以及 QQ 第二首播放且 libraryMetadataMatches=true 时仍报告等待条件超时；该条件已修正并单独复核，未当作后端失败或原条件成功。诊断 detailMetadataMatches 只属于最近一次显式 p0_verify_metadata 操作，切歌后须重查；没有 resolver metadata 时 resolved 字段为 false，不代表当前公开元数据缺失。

最终包在 QQ 第二页搜索单曲上验证：queueSize=1，暂停后 3 秒进度不变；继续后来源/实际取流元数据保持一致。seek 辅助曲尾后 ended=true、playing=false、failure=null、索引仍为 0，随后 resume 从头播放且 ended=false。原先单项播完后的无声与此末尾停止规则一致，但没有用后测的歌曲名称反推先测听音曲名。

## 验收边界

结束时三账号 CONNECTED，playing=false、playWhenReady=false、failure=null，音频故障注入计数 0，三平台元数据失败开关均关闭。保留原账号、缓存和平台歌单；未清数据、卸载、断开、换号、提交、推送或发布。
