# 后台播放可靠性与诊断

2026-11-18，第三优先后端交付。平台曲库、普通本地音频、CUE、DSF 继续使用现有 Media3 服务、队列和 Android 音频焦点。

## 失败与恢复规则

- 前台资格仍有 3 秒预算。旧轮询、过期的前台就绪或已取消的请求不能启动播放器。Media3 若在门控结束后才报告拒绝，且服务仍未在前台、当次仍想播放且尚未开始，则停止本次加载并报告 `BACKGROUND_RESTRICTED`；健康前台和已取消意图不受迟到通知影响。
- 取得前台资格并提交播放后，当前曲目连续等待准备超过 45 秒、已开始播放的曲目连续缓冲超过 60 秒时，释放本次加载，报告 `TIMEOUT`，保留队列、曲目与当前位置，等显式重试。时间从符合条件的连续缓冲开始，普通重复事件不续期。暂停、焦点或输出抑制、换曲和就绪使旧等待失效。定时到点优先于同时到期的缓冲上限。
- 暂时焦点中断继续交给 Media3；用户暂停、永久焦点丢失、耳机移除产生的 noisy 事件和输出长时间不可用会撤销等待中的播放意图。本轮的前台拒绝、缓冲超时和输出中断不触发自动换源，也不改变原平台来源失败的既有恢复规则。
- 新进程队列恢复仍只安装暂停态的元数据和位置。控制器重连不重发旧播放意图；旧恢复与新队列冲突时以新意图为准。定时仍属于现有播放服务，不在进程被杀后恢复或补播。

## 诊断读取

`PlaybackConnection.diagnostics` 提供最近 64 条进程内观察，连续相同事件合并。可区分控制器连接超时／拒绝／断开、服务创建、暂停恢复、前台超时／拒绝、焦点请求／抑制、准备、来源解析／失败、音轨格式、解码初始化／失败、输出、缓冲、实际播放与定时停止。来源解析成功只说明拿到读取能力，格式／解码事件才说明后续阶段到达。焦点拒绝与永久丢失使用 Media3 的回调和该曲目是否已经播放来判断，不推断具体 OEM 政策。

记录只含单调时间、状态枚举、媒体类型、平台、粗分类、Media3 数字错误码、连接次数和输出类型。无曲名、媒体 ID、路径、账号、链接或原始异常。MediaSession 对本地及在线播放器错误都只转发固定说明和错误码，原始错误继续供服务内恢复分类。生产诊断不落盘、不上传；调试包原有 `ss_snapshot` 固定入口可按需读取 `playbackTimeline`。系统冻结时进程无法按时执行回调；进程重启也不会保留旧诊断。

## 同包实机补验

用户提供独立窗口后，保留数据覆盖安装并核对主包和测试包散列。设备为 OPPO PJF110／Android 16；USB 充电，两轮扬声器锁屏观察的标准 Android device-idle 都为 `ACTIVE`。用临时生成的 M4B、Ogg、AAC、FLAC 和 M4A 验证真实解码，裸 ADTS AAC 未通过 40 秒定位，其余四份通过。

- **通知与焦点通过。** 调用 Musxi 通知实际的播放／暂停 `PendingIntent`。不同 UID 的独立测试应用申请临时焦点后，Musxi 暂停输出并保留播放意图；归还焦点后原位续播。中断期间用户动作式暂停、永久焦点丢失都清除播放意图，归还后不自动重播。测试应用不播放音频，也不模拟来电。
- **进程恢复通过。** 强停前后保持同一条临时音频和 `163729 ms` 的位置；新进程出现 `RESTORED_PAUSED`，没有重新准备、请求焦点或自动播放。该结果不代表整机重启已验。
- **静音样本的长锁屏与定时未通过。** 第一轮约 150 秒后采样停更，恢复时进度先外推到约 422 秒，再校正回约 160 秒；观察器发现回跳并取消刚启动的定时。第二轮不向进程发送广播或信号，ColorOS 日志明确记录 `ignore sys_silence audio` 和锁屏冻结，同时释放 ExoPlayer 的唤醒锁、代理 Binder；约两秒后 AudioFlinger 因供数不足移除音轨。接着读到 `cgroup.events` 的 `frozen 1`，尽管 AOSP 活动管理器仍将该进程列为前台服务且没有标记冻结。亮屏后才有新采样，第二轮没有启动定时。原样本为数字静音，设备的扬声器媒体音量另为零；恢复时的外推位置不能证明连续播放。没有据此改播放器或电池策略。
- **有声蓝牙下锁屏播放及定时通过。** 同编码、采样率和时长的非静音 M4A，经用户连接的蓝牙 A2DP 输出。最后一次熄屏后连续观察 `380827 ms`，23 次屏幕关闭且锁定的采样无进度回跳，最大采样间隔 `30024 ms`。60 秒定时启动后 `60130 ms` 观察到自动暂停，停在 `389028 ms`；锁屏下新诊断包含 `TIMER_STOPPED`，无错误、无剩余播放意图。重新打开后从库里读到同一进度，手动续播成功。对照同时改变了样本和输出，未分别测量数字静音、媒体零音量或路由的影响；仍处 USB 充电和标准 device-idle `ACTIVE`，不是深度 Doze 验收。
