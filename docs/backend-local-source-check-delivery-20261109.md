# 本地主动来源检查后端交付

日期：2026-11-09。用户授权接续本地后端，手机暂不能接入、CC 正式前端仍等待。本轮补用户选中条目的手动来源检查，并复用播放前读取判断；保留已有未提交代码，没有提交、推送、发布或操作平台账号与历史队列。前轮为[检索与批量整理](backend-local-organization-delivery-20261109.md)，现行接口详见[本地音频合同](frontend-backend-contract-local-audio.md)。

## 行为与实现

用户可选 1～500 条音频手动检查。初始 revision、ID 范围和存在性全部确认后才打开来源；一次只运行一批，公开进度、逐项结果、取消和全局错误。COPY 检查受管副本，不依赖已删除的原文件；REFERENCE 沿用原授权查询大小／修改时间，再读取首字节并关闭。未重新提取标签、复制或计算全量哈希，不更新元数据／来源／分组／进度／书签，不触发播放或后台轮询。

来源缺失、权限失败、不可读取及已知来源变化分别返回枚举，状态变化才写库；相同结果不增加 revision。可用性逐项保存，取消保留已完成结果、拒绝待提交观察，不回调成功。回调成功只表示处理完毕，前端仍需看各项错误，不能一概提示全部可用。重新检查成功可恢复 AVAILABLE。

短事务与提供方 I/O 分离，检查期间允许改名、整理、进度保存和播放。来源版本与代次守卫拒绝删除、重新关联（含相同 URI）、重新导入、目录重新授权以及新播放探测后的旧观察；进度与名称修改不使来源观察过期。新手动检查不会拒绝正在读取同一来源的合法播放，过期播放观察也不覆盖新检查状态。取消透传，避免把取消记成不可读。

文档元数据查询 null、EXTRA_LOADING 或 EXTRA_ERROR 均记为 READ_FAILED，明确空 cursor／文件不存在为 NOT_FOUND；未用临时云响应伪造空文件或不存在条目。缺少可选修改时间列的提供方继续沿用原 projection 回退。检查与播放共用轻量探测，COPY 播放前也尝试读取首字节。

没有新增运行时依赖、权限、数据库迁移或常驻任务，仍使用系统 SAF、SQLite、现有协程和 Media3。实际包体增量在阶段索引中以最终 APK 对照。

## 验证和证据

修改前为检索／整理轮：2060 项 JVM、Lint 0 错误／128 警告，debug APK 28,119,566 bytes，SHA-256 `be62cc6e09c078679df1811e96292828ded4c21e32b1f208a6126018f17d0a3b`。对照与回退点分别是 `.local/artifacts/local-source-check-20261109/baseline.json` 和 `.local/checkpoints/local-source-check-20261109/`；前轮冻结 source-files.json 保留源码身份。

新增流程测试覆盖首字节／关闭／无标签读取／无权限申请、复制原文件删除、受管副本长度变化与缺失、引用缺失／权限／空流／临时错误／修改时间变化、幂等重试、无效与过期选择、取消保留部分结果、检查期间编辑、删除／相同 URI 重新关联／重新授权，以及与播放双向交错。Android 文档查询的缺失与加载状态另有模拟提供方测试。并行子代理只负责文档查询两文件及只读竞态复核，主代理整合和验证。

实际预检查、失败尝试、最终测试计数、Lint、源码差异、包体与散列统一写入 `.local/artifacts/local-source-check-20261109/final-summary.json`。源码与文档冻结后运行 `scripts/verify.ps1`，强制重跑全部 JVM、Lint、主包和设备测试包编译、源码散列复核；只有该索引及其 verification summary 均为 passed 才记为本轮完整通过。

首轮预检查发现缺省授权代次的 `0` 与 Long 装箱比较导致来源误标 STALE_STATE，正常／权限／变化路径均被测试拦住；现统一使用 `0L`。该次失败单独留在 `test-build.log`，修正后重新构建，不将旧报告当作当前通过。

只读交叉审查还指出同源重新导入会误使播放探测过期，以及解绑后重连同一目录缺少授权代次更新。现将重新导入记为新观察，显式重新关联才推进来源代次；重新授予目录／文件权限也更新对应 grant 的观察边界，并补两项交错测试。第二次预检查为这些追加修正前的通过证据，最终验收另跑完整统一入口。

修正后的 `build.ps1 -Test` 预检查通过，报告合计 2079 项，0 失败／错误／跳过，比前轮增加 19 项（来源检查流程 17，文档提供方 2）。日志为 `.local/artifacts/local-source-check-20261109/test-build-3.log`。预检查可复用未变化模块的测试结果，完整统一验证强制重跑全部 JVM；两者分别留证。文档链接检查覆盖 105 份 Markdown。

## 体验与后续

当前检查验证首部可读与已知版本提示，不能证明所有字节无损或解码成功；没有可靠修改时间的同大小替换仍可能无法识别。调用系统提供方可能读取云文件，其阻塞调用需等返回才能完成取消清理；不承诺强行中止提供方内部任务。检查结果只是当次观察，实际播放仍会重验。

CC 可接“检查所选来源”，按逐项结果显示重试／重新关联，保留用户命名和进度。系统选择、跨重启授权、格式／长 seek、真实听音和后台仍待当前包专项实机。本轮没有设备安装或听音；后续优先正式页面与基础链路验收，倍速／AB／章节／本地 LRC／封面按实际需求安排。
