| 批次 | 范围与交付 | 验收边界 |
| --- | --- | --- |
| 1：CUE 解析与预览 | 动态解析曲目数量、编码、文件引用和时间；显式文件关联、缺失与歧义提示、有界导入预览 | 首版单一 FLAC；复杂多文件／间隙给明确阻断。只预览，不写曲库、不复制或改写来源 |
| 2：CUE 入库与播放 | 一份底层音频对应多个稳定曲目，段内进度、书签、队列、循环、定时、恢复、重复导入与引用回收 | 数据迁移／事务、真实播放边界、无缝衔接分别验收；不复制多份整轨 |
| 3：格式与输出信息 | 可确认的编码、采样率、位深、声道；区分源格式、解码格式与实际输出；核对平台音质偏好与回退 | 未知信息保持未知；文件 192kHz、平台无损标签和设备能力不等于实际输出 |
| 4：DSF／DSD 验证 | 有界 DSF 与标签解析、大文件偏移；评估 DSD→PCM 解码并通过后接入现有服务 | 先测定位、持续播放、内存、耗电、依赖体积与许可；倍率逐样本验收，原生 DSD 另评估 |
| 5：自定义音源 | 确定一个实际可接入对象，完成搜索／元数据／播放解析，再抽象来源身份与可选能力 | 账号隔离、受控解析、取消／超时／移除失效；选择任意应用不能自动取得其音频接口 |
| 6：USB 专项 | 有设备窗口后验证系统输出／原样输出能力，再评估直接 USB、DoP／原生 DSD | 手机系统、设备型号／固件、连接方向和格式协商；插拔、焦点、音量、回退与听音单独验证 |

顺序：先完成 1→2 的 CUE 闭环，再做 3；4、5按样本和接入对象穿插；6等待硬件条件。不为所有内容统一升采样，不因设备芯片规格承诺整条输出链路。

## 曲目数量与来源

曲目数依据有效曲目索引动态确定，不固定24。一份 FLAC + 10条有效音频轨得到10首；24条得到24首。多个文件按各条索引绑定；独立12首 DSF通常得到12首；没有可用索引的整轨保留为一条。INDEX00／01不是两首歌。无效／数据轨不能静默当正常曲目导入。

选择 CUE 与其音频时需识别关联；底层音频和可点播曲目分别建模，避免默认重复建整轨与分曲。CUE结构改变时不能按编号盲用旧进度。

## 当前样本与约束

朋友材料位于项目 `大祥提供-软件-音频文件/`，只用于本地研究与验收，不提交音乐或客户端。调查记录在 `.local/artifacts/friend-materials-review-20261114/README.md`。

- CD：44.1kHz／16bit／双声道 FLAC，73:57，CUE 24轨且需中文编码回退。无“(2)”音频严格解码失败；带“(2)”完整解码与PCM校验通过，CUE仍引用前者。必须允许显式关联；元数据可读不等于全文件完整。
- DSF：12首 DSD256，约10.4GiB；桌面片段解码通过不代替安卓验收。

- 海贝 R3 Pro Saber：本机解码规格不能替代 USB 输入规格；连接方式、版本、固件及实际设备能力待核对。
