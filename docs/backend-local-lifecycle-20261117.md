## 本轮改动

- 省略目录名时从系统 SAF 目录根读取显示名；显式名称优先。缺失／loading／error 游标与权限错误保守失败，不解析 URI 猜名称。
- 目录级错误与完整扫描内逐项失败分开。前者沿用 error，后者记录 results 及持久化 lastRefreshFailures；扫描失败／取消不覆盖上次成功扫描信息。重复刷新沿用既有身份去重和用户归属规则。
- imports 补 runId、completed、整批 error；sourceChecks 补 runId。新增 clearImport／clearSourceCheck，取消并使旧编号失效；所有进度、结束状态和 callback 依编号发布。原 cancel 继续保留已完成结果。
- 复用原取消清理：已入库条目保留，当前未提交副本／授权清理。clear 后仍保留 busy 直至清理完成；完成回调前释放槽位，支持回调串接下一轮。
- SQLite schema6→7 仅增加默认0的目录失败计数，保留第一部分双版本及现有库内容。runId 只在进程内有效，进程重启后不恢复／自动重放任务。

## 小而精核对

第一部分保留两个必要版本计数、一个明确命令 token 和查询依赖检查；旧 Long 接口只为兼容既有调用保留，未引入通用版本管理器。第二部分沿用两条现有任务路径，通过两个小的编号检查函数保护状态，没有引入通用任务框架。当前页面视觉和交互不扩展；任务错误不再误写为整个本地库错误。
