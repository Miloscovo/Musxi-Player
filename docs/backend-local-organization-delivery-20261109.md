## 本轮行为

本地库可按别名、内嵌标题、原文件名及作者检索，多词全部命中，兼容全／半角与忽略大小写。可选全库／某文件夹／未归组范围，并按复制／引用、已记录可用状态、未听／收听中／已完成及有书签筛选。分页限制 1～200 条，后续页绑定同一 revision，库变化后要求重查；新搜索及清空均拒绝迟到的旧结果。

查询仅使用数据库元数据，不打开来源、不联网、不扫描音频。只读结果排序与写回文件夹顺序分开：标题／文件名自然数字序、添加时间、时长及最近进度保存时间均可排序；未知值总在末尾，同值保留原范围顺序。最近收听按 `updatedAtMs`，不按播放位置。已显示页面过期时保留内容并标 `STALE_STATE`，服务保存进度也属于库变化，页面不得继续拼接旧页。

批量加入、移出和移动每次 1～500 条，冻结稳定 ID 列表，在事务内检查 revision、所有条目及最终容量。任何失败或提交前取消都整批回滚；ADD 复用已有归属，MOVE 先释放源归属再追加目标，允许满库净零移动。批量只改成员及必要源游标，保留音频、别名、进度、书签、其他归属、目录来源与授权，重复目录刷新不把用户移出的成员加回。

文件夹规则排序覆盖全体成员，不用当前筛选页重建文件夹；实际顺序未变不升 revision，不影响正在运行的临时队列。事务只读取目标文件夹相关音频／进度，避免为一个小文件夹额外物化全库书签、目录等数据。没有数据库迁移，仍为 schema 2；没有增加运行时依赖、Manifest 权限或常驻任务。
