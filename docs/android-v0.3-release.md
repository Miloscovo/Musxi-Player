# Musxi Player Android v0.3

Android v0.3，应用版本 **0.3.0**，versionCode **6**。这一版把 v0.2 之后的本地音频、歌词、个性化与交互进展汇入同一个正式安装包，并继续完善播放与平台后台能力。

安装包与对应源码发布在 [独立安卓仓库 v0.3](https://github.com/qwt1011/Musxi-Player-Android/releases/tag/v0.3.0)，安卓源码另向 [PC 上游 android/development](https://github.com/Miloscovo/Musxi-Player/tree/android/development) 提交，不改变 PC 主线。Release 标签使用 `v0.3.0`，与应用内更新清单的 `0.3.0` 精确匹配。

## 下载与升级

- `Musxi-Player-0.3.0.apk`：正式签名包，支持 Android 8.0 / API 26 及以上。
- `SHA256SUMS.txt`：安装包 SHA-256 校验值。
- `update-manifest.json`：供应用内更新读取的版本、大小、散列与公开签名证书指纹。

正式包仍为 `tech.musxi.player`，沿用 v0.2 的长期发布签名；已安装 v0.2 的用户可直接覆盖更新，保留该包的账号、设置和应用数据。建议保留原有音频文件与文件夹访问权限。旧开发包 `tech.musxi.player.dev` 可并存，数据独立，不会自动迁移到正式包。

## 本地音频拥有独立入口

曲库新增独立的本地音频分区，面向音乐、音声、有声书及录音，提供文件夹、未归入条目、导入进度和继续播放入口。

- 选择单个／多个文件，或导入文件夹；支持复制到Musxi，以及授权读取原文件。可关联手机目录，后续手动刷新。
- 多选加入、移出或移动到文件夹，支持新建文件夹、条目与文件夹改名，以及未归入条目的管理。
- 记录播放进度，创建、改名和删除书签；按本地条目记忆播放速度，切回平台歌曲恢复1倍。
- 使用内嵌图或视频截帧生成自动封面，也可设置、裁切和恢复手动封面；保留不同EXIF方向的处理。
- 支持从视频容器播放音轨，界面标明本地内容；本版不提供视频画面。
- 检查来源是否可读，重新授权目录或关联文件，并显示不可用条目的状态。

本地音频使用同一播放服务与通知控制，不另起一套播放器。普通缓存清理不会删除本地库、书签和用户导入副本。本地检索筛选、规则排序、原始音频导出与整理备份的后台接口也有进展，正式入口仍需后续接线，本版不将它们作为已开放页面功能。

## 歌词与播放更连贯

- 三平台接入KRC／QRC／YRC字级时间，当前歌词行可按字高亮；跟随真实播放位置和速度，暂停、缓冲时停止推算。
- 保留原文／译文分层和手动匹配，补充字号选择、歌词偏移及文种相关的译文显示策略；切歌和换源防止旧歌词串入。
- 封面与歌词在同一播放器中连续切换，转场可以中途打断并反向，底部工具增加对应按压反馈。
- 新增可选的“媒体卡片显示歌词”，默认关闭。开启后系统媒体标题使用当前原句，蓝牙／车机显示的歌名也可能随之变化；关闭时恢复原标题。

## 背景与外观可分别调整

界面壁纸和播放页壁纸独立保存，可复用已导入图片；支持移动取景、缩放、预览应用和取消。背景强度范围扩大为0～150，沿用当前文字可读性处理。

主题色和深色模式持久化，“我的”页使用就地选择菜单，减少来回跳转。玻璃材质继续按系统能力回退，关闭透明效果时使用相应实色表现。

## 曲库与队列使用体验

- 曲库接入推荐入口，网易云／酷狗为每日歌曲，QQ为“猜你喜欢”；提供显示开关、刷新和点播，按当前平台账号隔离结果。
- 歌单内搜索与缓存补全继续完善，提供读取进度、取消及有界加载；长列表增加接近底部继续加载。
- 长按爱心使用“收藏到”面板，普通歌单收录与红心分别处理，按逐目标读回结果反馈。
- 队列按已播放与接下来播放分区，支持拖动、移除及撤销；外部变化时通过revision校验避免旧手势操作新队列。
- 播放进度显示、滚动停靠栏、分区切换手势与按钮触感继续优化。另有多项后台能力完成接入与回归，为后续界面扩展做好准备。

## 定时停止与应用更新

定时停止提供分钟倒计时、播完当前曲、到点后播完当前曲三种策略，平台与本地播放共用服务管理。

应用内更新改为更清楚的版本信息与分步下载／安装面板，展示日期、大小和更新说明。沿用来源限制、下载大小与SHA-256核对、包名／版本／签名检查，再进入Android系统安装确认；不在仓库中保存或分发私钥。

- 账号权益、版权、网络和官方接口变化会影响平台播放；推荐和不同账号的可播放性仍需更多样本。
- 字级歌词是否可用取决于实际来源；真人听音对齐和各类语言／版本仍需补验。
- 本地格式支持受解封装和设备解码能力影响，裸AAC精确跳转、特殊文件提供方尚有已知限制；不宣称支持CUE分轨、DSF／原生DSD或独占输出。
- 长时间连续熄屏、来电、蓝牙／外接设备、不同Android版本及高强度壁纸可读性尚未全矩阵验收。
- 自动化截图验证布局，不代替真实设备上的流畅度、声音和后台存活验收。
