## 新增能力

- 整张他人普通歌单的统一订阅快照和设置入口：账号代次校验、写前新鲜读取、保留意图冲突、同平台互斥、单次写入、写后核实。响应丢失时照常回读，无法核实则明确 `UNKNOWN`，不自动反向补偿或重试。
- QQ 整单收藏/取消收藏，依据官方网页公开协议，使用现有账号与固定 musicu 通道；收藏归属必须完整读取，不以一页缺失证明未收藏。
- 网易云整单订阅：新鲜匿名 v3 令牌、严格 JSONP 解析、固定主机和响应大小边界，令牌放入 EAPI 加密 header 与 Cookie，未引入远端脚本执行、浏览器 SDK 或新运行依赖。上游订阅默认 v2，v3 替代需要实机验证，接口失败不自动重试。
- 酷狗本人普通歌单改名：独立的云歌单 AES/RSA 协议，只接受明确的七字段载荷；原排序、标签、简介读取完整后才写，写后回读核对，不用空默认值覆盖远端资料。

## 本包实机专项

手机重连并解锁后，覆盖安装上述主包与测试包，保留账号数据；显式运行 `PlaylistMembershipDeviceTest`，携带已授权的 `allowPlatformWrites=true`。执行与恢复证据保留于 `.local/artifacts/playlist-followup-20261106/device/`。

| 平台 | 实际结果 | 写入与恢复 |
| --- | --- | --- |
| 酷狗 | 通过 | 当前账号的现有空普通可写歌单：添加一首、重复提交不再次添加、移除；完整顺序恢复到原 0 首，红心完整列表不变，恢复记录关闭。 |
| 网易云 | 跳过 | 当前账号没有现有普通可写歌单；没有开始写入，不能算通过。 |
