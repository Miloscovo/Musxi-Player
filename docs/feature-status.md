## 后端剩余优先级

1. 优先配合正式页面验收主题色和逐字时钟；本地音频下一批先拆整理／进度 revision 与分页 token，再补目录名和错误分离、结果生命周期。reorder 过期错误和单选选择器已补；完整七项排期见[需求交付](backend-requests-20261111.md#本地音频七项状态与排期)。继续验证导入／播放／导出／恢复及正式 Activity 的长 COPY 临时权限。
2. 视频只听声音、倍速、自动/手动封面与书签改名后端已补，配合 CC 接类型、设置、封面/补图与播放入口及同包实机验收；快进退沿用seekTo，观看页面仍待设计。AB、本地 LRC/章节为后续增强；包含音频的一键迁移包另评估。
3. 歌单协议缺口保留：网易云兼容 v2、酷狗整单订阅、QQ 创建不确定对账；不因缺手机而自动进行平台写入。
