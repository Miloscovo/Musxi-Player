# Liquid glass

“设置 → 外观 → 液态玻璃”默认关闭，保存选择；开关同时控制侧边栏、播放栏和歌曲信息组件，关闭后恢复原背景。侧边栏、播放栏的透明程度只控制底色，100% 时仍保留固定的模糊、折射与轻微高光，关闭液态玻璃才移除这些效果。歌曲信息独立透明度保持原规则，全透明时不额外留下材质。文字、封面和控件保持清晰。壁纸预览中的设置沿用预览／应用／取消流程，不提前覆盖已保存偏好。

“自定义静态壁纸”开关不受透明效果开关限制，初始化或文件处理期间仍暂时禁用。开启壁纸同步开启透明效果，关闭壁纸同步关闭透明效果；主题模式、色调、透明程度和已保存图片保留。“恢复默认”仍只重置壁纸，不联动关闭透明效果。

侧边栏和播放栏使用同一 CEF 页面内的背景折射与模糊。歌曲信息属于独立 CEF 窗口，采用静态玻璃材质，不采样其背后的游戏或桌面画面。没有鼠标形变、持续计时器或游戏画面捕获；实际滤镜开销仍取决于显示尺寸、背景变化和 GPU 负载。

折射以固定约 12px 的渐变边缘遮罩收敛，基础背景模糊为 8px、边缘模糊为 2px；窗口最大化时边缘范围不随面板拉长。侧边栏高光较弱，播放栏略明显，两者的效果强度与底色透明度分开。歌曲信息仍采用随其背景透明度变化的静态材质。播放栏底色透明需同时开启“透明效果”和“播放栏透明”，不自动修改任何透明设置；底色不透明时，背景滤镜会被底色遮住。

复用 `rdev/liquid-glass-react` 固定提交的位移图与背景滤镜方式，仅保留一个位移通道、轻度模糊和静态高光。来源与完整 MIT 许可见 `THIRD_PARTY_NOTICES.md`、`licenses/liquid-glass-react-LICENSE.txt`。未添加 npm 依赖或放宽 CEF CSP。

验证：前端外观测试覆盖默认值、保存和壁纸预览回滚；`tests/cef-game-overlay.ps1 -GlassOnly` 用实际 CEF 截图像素对比折射与单独模糊，并检查跨窗口同步、全透明文字和编辑拖动命中。`-FocusOnly`、`-ResizeOnly` 覆盖组件焦点及真实边缘拉伸。
