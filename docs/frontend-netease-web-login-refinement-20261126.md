## 需求与实现

- 官方WebView负责手机号、验证码、登录与条款，Musxi不替代官方表单、不注入DOM改色。允许域内HTTPS沿用原导航保护，不能承诺所有外部协议或条款域名均能打开。
- 自绘平台标识沿用网易云6dp圆点，错误提示沿用dialogDangerFill与现有深色警示文字。旧样张的仿logo／仿表单不再作为当前设计。
- 使用MainShell现有GlassHost内的MusxiSheet FULL，响应透明设置与现有系统降级、拖拽／触感；网页区域是不透明白色20dp圆角卡片，两侧12dp。
- 按用户后续明确选择，底部“完成登录并验证”采用cs.primary/onPrimary随当前主题Accent切换；没有自动循环色彩动画。
- 保留简洁顶栏与按需提示，减少工程术语；说明放按钮上方，键盘或大字体时隐藏次要说明，safeDrawing与IME避让。小屏／横屏可用性以测试及渲染结果为准。
- 生命周期修补：AndroidView按session隔离；退出动画保留显示状态；FLAG_SECURE挂在实际Sheet内容生命周期，退出动画期间继续保护，只清除登录外壳自己添加的标记，不清原窗口已有标记。

本轮生产修改限定NeteaseWebLoginSheet.kt，设计占位文件复核后沿用。相关UI和设计测试完善命名参数、窄屏／大字／横屏／非透明几何和关键动作。MainShell与accounts／平台协议无需本轮变更；保留现有原位重认证、关闭不退出及扫码切换。
