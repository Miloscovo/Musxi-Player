# v0.1 开发基础：PR #24 之后的增量

2026-10-23，源码版本 `0.1.0-alpha02`。**v0.1 非常不完善，这次提交只是为后续修改和实机测试奠定基础，不是正式稳定发布。**

PC 来源为 [Miloscovo/Musxi-Player](https://github.com/Miloscovo/Musxi-Player)，后续安卓开发保存于 [qwt1011/Musxi-Player-Android](https://github.com/qwt1011/Musxi-Player-Android)。本次仍向 PC 上游的 android/development 提交代码 PR。

## 对比基线

上次 [PR #24](https://github.com/Miloscovo/Musxi-Player/pull/24) 已合并，归档 P0/P1/P2 后端能力；其 head 为 ac3ac80，上游 merge 为 c5821a7。本次上游提交直接基于该 merge，避免重复提交上次 PR 内容。

独立安卓仓库初始提交保留本次完整安卓源码树、版权和第三方声明；上游 PR 使用同一源码树，两个目的的提交历史不同。独立仓库不携入整个 PC 历史，仍保留明确来源与基线。

## 新增与整合

- 正式 Compose 应用外壳、账号、曲库/歌单/搜索页面、迷你/全屏播放器及换源面板。
- 三平台行级双语歌词、原文先发/译文后补、开关/独立刷新、语言默认值；字体层级、操作对齐、字形居中及上下留白。
- 红心与收藏写后核实、曲库失效联动；队列点击、拖动/删除/清空。新增按索引导航命令，保留原票据；revision、账号/连接门禁、外部变更取消及失败反馈。
- 连接恢复与有限恢复、后台前台资格门禁、AUDIO 独立请求通道、保守来源匹配和固定 debug 验收工具。
- PC exe 同源品牌图标、安卓密度资源；alpha02 修复自适应前景满铺导致的主标识裁切。
- 公开文档入口与构建说明归一；本机设备/工作日志、未采用候选、APK 和快照归档到忽略的 .local/。

## 验证与限制

alpha02 构建及 603 项 JVM 测试通过，六模块 Lint 0 错误/83 警告，Android 16 覆盖安装与系统图标检查。alpha01 已有 3 项正式页面设备测试和部分真实播放/歌词/通知/后台换源证据；听音与曲目由使用者确认。两个包的证据分别记录，详见 [0.1 验收](android-0.1-acceptance.md)。

恢复队列/最近播放缺产品入口，封面/主题/更多/输出选择仍不完整；逐字歌词未做。队列编辑、全平台主流程、完整视觉、自然长后台/深度 Doze、系统回收、来电/输出切换等仍待验证。源码公开不代表这些缺口关闭，也没有发布 Release 或正式签名 APK。
