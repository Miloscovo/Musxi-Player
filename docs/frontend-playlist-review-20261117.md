# 歌单前端接入审查与本地库回归修复

2026-11-17。用户报告 Kimi 隔离歌单前端安装后，本地音频库“暂时打不开”、酷狗歌单无法读取，要求排查并审查前端。此次修复在唯一主目录整合前端与当前 CUE／DSF 后端，不提交、推送或发布，不执行平台创建／改名／删除、收藏或账号切换。

## 已确认的问题

1. **安装了旧后端包。** 歌单工作树基于已提交的 `e898332`，没有主目录未提交的 CUE／DSF 源码。手机本地 SQLite 已为 schema 5，但该工作树只认识 schema 4。旧包覆盖安装到同一个 `.dev` 包名会触发拒绝降级；保留数据安装不能保证新旧数据库兼容。实机导出库 `integrity_check=ok`，原音频、文件夹、成员、进度、书签各一行，目录关联零行，数据未丢失。修复使用当前 schema 5 后端，不降低数据库版本或重建库。
2. **目录误拒酷狗分页。** `KugouLibraryApi` 在未知总数时，短页仍返回请求步长对应的 `nextOffset=30`，需要下一页空响应才能确认结束。`PlaylistCatalog` 原先强制下一 offset 等于已返回行数，导致合法短页被拒为 `protocol`。为目录增加可选 `continuationStride`，账号装配仅为酷狗设置 30；保留其余平台原校验，以及平台、重复 ID、异常总数、空非终页等检查，不猜测短页已结束。
3. **歌单详情订阅丢失。** 前端改为观察统一 catalog 时移除了旧曲目 browser 的三个订阅，详情 `merge(LibraryBrowseState)` 不再收到结果。恢复独立详情订阅，并让无页面的首次读取失败也结束 loading、显示错误。
4. **操作弹窗可能卡死。** 账号代次／页面变化后忽略旧回调，却保留 submitting 弹窗，导致无法关闭或恢复。切换时关闭旧上下文弹窗，继续忽略旧回调；同一弹窗在途时拒绝用新弹窗替换，不自动重放远端请求。
5. **列表失去逐项懒加载。** 全部歌单原先嵌在单个 lazy item，长列表会一次组合所有行，分页接近末尾判断也失真。恢复每首歌单独立 item，共享拖动状态，保留固定 revision、变化取消与单次保存。菜单锚定当前行／网格单元，不放到可能未组合的列表末尾。
6. **生命周期与旧闭包。** 目录生命周期补平台 key，避免切平台后释放旧实例却遗漏当前实例；删除完成回调从 ViewModel 当前值核对详情目标，避免读取 remember 捕获的旧 tracks。
