# Musxi Player 0.4.0

Windows x64 测试版安装包：**MusxiPlayer-Setup-0.4.0.exe**。

## 新增功能

- 同时登录网易云音乐、QQ 音乐和酷狗概念版，合并展示歌单，账号管理显示头像、会员状态及可获取的到期时间。
- 搜索结果合并同名、同歌手、同专辑的歌曲，显示支持平台标签；播放时自动尝试可播放的平台，也可在播放栏切换来源。
- 云端收藏整合汇集已登录平台的收藏歌曲，支持按平台收藏、取消收藏及添加到歌单。
- 完善最近播放，保存记录并合并跨平台重复歌曲；重启后恢复播放栏、播放进度和队列，保持暂停。
- 新增全屏歌词页、本地与三平台在线歌词、独立查询通道及缓存，支持逐行高亮和点击歌词跳转。
- 本地歌曲可搜索、预览并指定在线歌词，支持前后 600 秒时间校正和恢复自动选择；不改写原音频或原歌词文件。
- 外观设置增加跟随系统、独立透明效果和绿色、蓝色、粉色、红色色调；播放设置支持默认音质及立即切换音频输出设备。

## 修复与优化

- 修复窗口控制按钮和播放栏菜单部分区域无法点击，以及高 DPI 缩放下的显示问题。
- 修复账号头像及歌单封面显示；自动补充歌单封面使用列表第一首歌曲，保留手动设置的封面。
- 改善深浅色主题、按钮悬停、无封面占位图、平台标签及滚动条的色调适配。
- 支持音量图标点击静音并恢复原音量；修复损坏的歌词匹配记录无法恢复自动选择的问题。

## 使用说明

- 在线播放、音质、歌词和会员信息受平台接口、账号权限与版权限制影响，不保证每首歌曲均可用。
- 本地歌曲保持原始音质，不能直接收藏或添加到在线歌单。
- 歌词整体偏移不能修复不同录音、剪辑或变速；移动或重命名本地文件后可能需要重新匹配。
