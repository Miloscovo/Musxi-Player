## 后端范围与数据保护

- `linkDirectory / refreshDirectory / reauthorizeDirectory / unlinkDirectory`；`state.directories` 只公开名称、模式、递归偏好、上次完成时间、缺失数量及枚举错误。
- COPY 关联也保留持久目录授权，以后可以主动发现新增；原 `importDirectory` 保持单次导入语义。导入、刷新共用串行批次、进度和取消入口，不新增常驻扫描器。
- 目录来源记录与音频导入在同一事务提交。已有成员不重排，新增文件追加，用户手动移出的已知来源不被重新加入；别名、进度和书签保留。
- 完整列举成功后才计算缺失；查询失败、取消、云提供方加载中或范围超限都不当作空目录。COPY 缺失只记来源数量，副本仍可播；REFERENCE 缺失保留数据并标记 `MISSING`。逐项读取错误保留在结果中，不伪装为整批全部成功。
- 来源大小/修改时间只作为提供方提示。COPY 的可靠提示均相同且受管副本存在时复用，否则重新读取并内容去重；内容变化产生新音频，不把旧进度套给新录音。REFERENCE 已知版本变化拒绝，等待用户显式重新关联。
- 取消关联只删目录及来源记录，删除应用文件夹也保留音频本体；授权在没有剩余关联、音频引用或活跃导入后才释放。扫描期间取消关联、重新授权或删除目标时，旧结果提交前再次核对。

SQLite 由 v1 加法升级到 v2，添加修改时间、目录和来源表，保留既有 ID、别名、成员、进度、游标和书签。未知版本或迁移失败报告错误，不重建空库。最多 500 份目录关联，每次最多 500 个音频、检查最多 20,000 个目录条目，范围超限明确失败。
