# Musxi Player Android v0.3.1

应用版本 **0.3.1 / versionCode 7**。本版汇总 v0.3.0 之后的前后端进展，重点是三平台账号与播放稳定性、歌单和队列一致性、本地音频，以及统一浮卡和锁屏歌词界面。

正式包名仍为 `tech.musxi.player`，沿用 v0.2 / v0.3.0 的长期发布签名。支持 Android 8.0 / API 26 及以上，可覆盖安装正式旧版并保留其数据。开发包 `tech.musxi.player.dev` 与正式包数据独立。

下载位于 [安卓仓库 v0.3.1](https://github.com/qwt1011/Musxi-Player-Android/releases/tag/v0.3.1)：`Musxi-Player-0.3.1.apk`、`SHA256SUMS.txt` 和 `update-manifest.json`。PC 上游同步目标为 `android/development`，不改 PC 主线，也不将安卓安装包作为 PC 版本发布。

## 登录与账号

- 三平台区分凭据过期、网络故障与可重试错误；恢复网络后按条件恢复校验，避免把临时断网直接当成退出。
- 账号工作按平台隔离，重新授权使用候选会话；失败或取消时保留原账号，旧请求不覆盖新一轮结果。
- QQ 官方授权使用独立任务，修复重新登录后回到桌面的现象，用户已实测正常返回。
- 酷狗授权期间，在已有悬浮窗许可时使用临时可见状态条，成功保存后尝试返回 Musxi；取消、超时和完成会移除。没有该许可或系统拒绝时仍可手动返回，不保证所有系统自动回跳。
- 网易云网页登录沿用真实官方网页，外壳统一到 Musxi 的 Sheet 和玻璃材质；底部验证按钮跟随主题色，改善关闭、重开、窗口安全标记及窄屏／大字布局。用户已反馈大部分网页登录实测正常。

网易云仍保留相册扫码：未登录账号页可选择“网易云网页登录打不开？改用扫码登录”，生成临时二维码后在网易云扫一扫中从相册选择并确认。正常网页浮层内的常驻扫码切换入口尚未增加，本版没有把该讨论建议算作已实现。

## 播放、搜索与队列

- 适配网易云 XEAPI 取流，修复此前播放接口不可用的问题。
- 统一三平台播放请求取消与迟到结果保护；切歌或取消后停止后续音质回退，资源失效时按现有有界规则重新获取。
- 修复酷狗无损变体识别与现有官方地址兼容；音质继续以歌曲、账号权益和实际接口返回为准。
- QQ／酷狗长歌单补全前校验已有前缀，防止分页变化引发漏歌或乱序；恢复队列保持身份及暂停状态。
- 曲库关闭后失效保留原展示快照，减少返回时闪空；写入丢响应时对支持的操作执行只读核实。
- 搜索、推荐元数据和歌词匹配候选采用快照与取消门禁，避免旧响应串入新查询或新来源。

## 本地音频与歌单

- 正常启用本地 DSF：支持 DSD64／128／256、单／双声道解码到 176.4 kHz 浮点 PCM，再交给现有系统音频输出；复用复制／引用导入及播放服务。单声道有自动化覆盖，未独立实机验收。
- CUE 单 FLAC 的解析预览、分曲入库、分段播放、进度与备份后端已完成；独立正式 CUE 导入界面仍待接入，不作为本版开放入口。
- 本地库升级与整理、播放进度使用不同版本，减少边听边整理的冲突；完善目录刷新、来源检查、取消及完成结果生命周期。
- 歌单新建、改名、删除和 Musxi 内排序界面接入统一目录与权限判断；继续改善目录续页、详情订阅和刷新。

## 界面与锁屏歌词

- 新建歌单、本地条目删除与改名等对话框采用同窗口 Musxi 浮层，统一遮罩、返回、键盘和触感处理。
- 账号管理改为就地菜单，退出登录保留明确确认；本地书签、歌词匹配、收藏到和播放器菜单继续统一交互。
- 接入正式锁屏歌词页及独立设置入口，提供关闭、媒体卡片和歌词页三种模式。歌词页复用当前歌词和已应用播放页壁纸，可通过四方向滑动退出；实际触发仍受系统权限与后台策略影响，默认不自动开启。

## 验证与已知边界

本版重新执行统一 JVM 测试、debug Lint、主包／设备测试包编译及源码冻结检查，并完成正式签名、release Lint、包名／版本／证书与调试入口隔离检查；各日期记录只证明对应包与样本。

本次统一验证已通过：**3,178项测试，失败／错误／跳过均0，debug Lint0错误165警告**，主包和设备测试包编译、1,093条源码路径冻结通过。证据`.local/artifacts/verification/20261127T064902391Z-27496/`。正式APK为19,591,250字节，SHA-256 `8c29dacb6ceb8903e0738d4e21131b66188c39af8d4ed883e8a112183e2acad2`；v2验签、包名／版本／清单和四个DEX中的固定调试类隔离检查通过，公开证书与v0.2／v0.3.0一致。正式包已在PJF110／Android16首次安装启动，设备base.apk散列相同且采样未见FATAL EXCEPTION；未在正式包重复账号登录／播放，也未实测旧正式版覆盖升级。独立release Lint为0错误54警告。正式包证据`.local/artifacts/release-0.3.1/`及`.local/artifacts/release-v0.3.1-preparation/`。验证后仅回填结果文档，生产源码未变。

已有开发包实机覆盖三平台真实取消、酷狗942首分页补全与中途停止、跨进程暂停恢复、搜索／歌词预览，以及网易云约20分钟本地播放能力自然到期后的重新取流。它们不能替代本次正式签名包的全部设备检查。

仍保留以下限制：

- 自然 CDN 签名拒绝后的刷新、网易云／QQ 千首级歌单、真实远端并发编辑及更多账号样本尚未全量覆盖。
- DSF 不提供原生 DSD、DoP、USB 独占、DFF／DST、DSD512 或多声道；PCM 解码采样率不代表设备物理输出采样率。CUE 多文件、无缝听感与分曲导出尚未开放或验证。
- 锁屏歌词正式页的完整权限／动作／四方向手势和更多系统仍待实机矩阵，历史调试宿主通过不等于所有设备通过。
- 网易云官方验证码与授权确认由使用者完成；用户反馈网页登录大部分正常，自动化键盘验证曾停在官方条款确认。一次收尾发现账号已断开且原因未确认，测试未执行退出／凭据清除／提交，保留在专项记录，未擅自恢复旧凭据。
- 本地检索筛选、规则排序、导出与整理备份等已有后端能力，独立正式页面仍按需接入。长时间 Doze、来电和更多蓝牙／外接设备继续补验。
