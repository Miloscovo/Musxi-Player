# 后端现状（更新至 2026-10-23）

文件名保留以兼容既有引用。当前源码 `0.1.0-alpha02`，仍是很不完善的 v0.1 开发基础。统一入口：[集成验收](android-0.1-acceptance.md)、[开发接续](next-session-handoff.md)。

| 范围 | 已实现 | 待完成或验证 |
| --- | --- | --- |
| 账号与曲库 | 三平台官方连接、验证、加密保存、generation 隔离；歌单/歌曲/搜索分页与元数据缓存 | 正式页面逐平台完整流程与失败矩阵 |
| 播放与来源 | Media3、模式/seek/上下首、有限重试、保守候选、后台前台资格门禁 | 深度 Doze、真实回收、来电/输出等；一个后台换源成功样本不代表所有系统情形 |
| 队列 | revision、原 timeline 跳转、移动/删除/清空/插入/追加 | 正式拖动和旧 revision 拒绝矩阵实机验收 |
| 收藏与持久化 | 写后核实、曲库失效、journal 与最近播放 | 恢复与最近播放缺产品入口 |
| 歌词 | 三平台行级译文、原文先发/译文后补、独立刷新 | 逐字/QRC 未实现，完整视觉矩阵待验 |
| 调度 | AUDIO 独立串行、加锁会话快照、generation 门禁、脱敏聚合 | 非音频请求仍可能互相等待，不保证立即中断 HTTP |
