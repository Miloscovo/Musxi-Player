# Musxi Player 0.7.0

## 在线加载与播放

- 启动时优先显示上次成功同步的歌单目录，账号验证完成后各平台分别开放操作，减少等待。
- 将 VIP、收藏数量、封面和头像等附加加载移至后台，移除歌单入口固定等待时间。
- 优化网易云、QQ 音乐与酷狗歌曲列表获取，支持分批展示和点播已加载歌曲。
- 对支持顺序读取的在线音频提前开始解码，优化点击播放、缓存复用、失败重试及连续播放响应。
- 移除歌曲列表中的“已显示 x 首，正在更新歌单”提示，保留加载失败后的重试入口。

## 动态壁纸与外观

- 新增 Wallpaper 动态壁纸扩展，可发现本机 Wallpaper Engine 资源或添加目录，支持 Scene 与 Video 壁纸预览和应用。
- 支持壁纸帧率与画质设置，窗口不可见时暂停或释放资源；部分场景特效可能不受支持。
- 更新应用图标，调整壁纸、外观及游戏叠加层相关界面。

## 安装与源码

- Windows x64 安装包：`MusxiPlayer-Setup-0.7.0.exe`。
- `MusxiPlayer-Update-0.7.0.json` 为应用更新校验清单，无需手动打开。
- 本版本应用源码：[v0.7.0](https://github.com/Miloscovo/Musxi-Player/tree/v0.7.0)。
- 第三方源码、固定版本、许可证与重链接材料获取说明：[源码交付索引](https://github.com/Miloscovo/Musxi-Player/blob/efd72195e2202325c8a8af8b79068f63ccd1cd18/docs/release-source-delivery.md)。

首次启动需成功同步以建立歌单缓存；在线响应速度仍受平台接口与网络状况影响。动态壁纸资源需自行提供。
