Musxi Player KuGou Android Login PoC
Based on Musxi Player, Copyright (c) 2026 Miloscovo and contributors.
Android login PoC additions: 2026-10-18. GPL-3.0-or-later.

Request parameter/signature and RSA compatibility code is adapted from
MakcRe/KuGouMusicApi 1.6.0, commit a5a98013cce79fe0ae2ad65fc84b68176ebcfc1e.
Copyright (c) 2023 MakcRe. MIT license retained in licenses/KuGouMusicApi-MIT.txt.
The included public protocol constants and public RSA key are upstream protocol
material, not a user's private credentials. Platform authorization is separate
from the source-code license. No account material is included in this APK.

The optional direct-open URI follows the official public authorization page's
openKugouApp script observed on 2026-10-18. This is a compatibility experiment,
not a claim of official SDK integration or authorization by KuGou.

Source for this work belongs with the matching APK:
android/player/platform-kugou/ in the accompanying Musxi Player source checkout.
This local experimental build has not been published as an official release.

No additional third-party runtime library is bundled. Android framework classes
are supplied by the device. JSON-java 20240303 is a host-test-only dependency,
is public domain, and is not bundled in the APK.

The read-only library adapter also adapts module/user_playlist.js,
module/playlist_track_all_new.js, module/search.js, module/song_url.js and util/helper/request
from the same pinned MIT source. Standard account-authorized playback only;
trial media is rejected. No new production dependency is included.

2026-10-20 favorite synchronization additionally adapts
module/playlist_tracks_add.js and module/playlist_tracks_del.js from the same
pinned MIT source for supported single-track favorite add/remove operations.
No new production dependency or license change is included.

2026-10-20 standard LRC requests additionally adapt module/search_lyric.js
and module/lyric.js from the same pinned source, with fmt=lrc and bounded
Base64/UTF-8 decoding. KRC/word-level decryption is not included.
Local compatibility change: use the same official HTTPS host's /search route
instead of /v1/search (empty HTTP 200 response observed on host and device).
Source identifiers, signing and standard LRC download/decoding are retained.
