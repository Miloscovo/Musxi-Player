On 2026-09-30, the user confirmed individual development, installation of Visual Studio Community 2026, and acceptance of its license terms. No linking configuration was changed.
- **Windows system D3DCompiler test — passed on the audit machine.** An isolated Release copy without the application-local `d3dcompiler_47.dll` passed the existing CEF smoke test with exit code 0 and was observed loading `C:\windows\SYSTEM32\D3DCompiler_47.dll`. This provides a tested alternative to SDK-copy redistribution, not a blanket clearance for the current installer or every supported GPU/Windows configuration.
