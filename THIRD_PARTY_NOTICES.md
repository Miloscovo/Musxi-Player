This inventory records the Windows x64 application produced by the current source build and installer configuration. Versions come from the configured SDKs, binary version output, vendored revision, and npm lockfiles. License files listed below are upstream copies or the unmodified license section included in the published package README. The existing `dist/` installer is stale and is not used as the inventory baseline.

The current installer source is `installer/MusxiPlayerUpgrade.iss`; it installs the CEF/Chromium runtime files, the React `frontend/dist` bundle, the four FFmpeg DLLs linked by CMake, the Node runtime, the service adapter and vendor source, and service `node_modules`. It does not ship `frontend/node_modules` or build tools.

GNU's [System Libraries FAQ](https://www.gnu.org/licenses/gpl-faq.html#SystemLibraryException) permits linked executables containing qualifying proprietary compiler runtime libraries. On 2026-09-30, the user confirmed individual development, installation of Visual Studio Community 2026, and acceptance of its license terms. This closes the outstanding entitlement declaration based on the publisher's statement, not independent verification or retroactive authorization of earlier builds. Rebuild the release binary under the confirmed authorization before publication. Evidence and scope are recorded in [GPL-Compatibility-Review.md](licenses/GPL-Compatibility-Review.md). No linking configuration was changed.
- **Windows system D3DCompiler test — passed on the audit machine.** An isolated Release copy without the application-local `d3dcompiler_47.dll` passed the existing CEF smoke test with exit code 0 and was observed loading `C:\windows\SYSTEM32\D3DCompiler_47.dll`. Microsoft confirms Windows 10 includes this component. This provides a tested alternative to SDK-copy redistribution, not a blanket clearance for the current installer or every supported GPU/Windows configuration. See [test evidence and scope](licenses/GPL-Compatibility-Review.md). The installer rules now exclude the SDK copy and display the project GPL license; broader Windows/GPU coverage remains outside this machine's test evidence.
- **FFmpeg and corresponding source.** LGPL-licensed libraries can be used with GPLv3-covered code subject to their actual license conditions; their own licenses remain unchanged. A GPL binary release must additionally provide matching Corresponding Source for Musxi Player and the required build/install materials under an applicable GPLv3 section 6 distribution method; the FFmpeg-only source assets do not replace the application's own Corresponding Source.
- **Future packaging versus existing artifacts.** Both `.iss` files already copy the repository root `LICENSE` into the installation directory, so subsequent packaging will include the new official GPLv3 text. They also continue to copy all existing third-party license materials. The new 0.2.0 installer is rebuilt separately after the migration.
